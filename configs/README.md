# configs

`final.json` holds the settings of every stage of `run_all.py`, copied from the CFG cells of the Colab notebooks that
produced the selected submission (v8, v10, v11, v13, v13.1, v14, v15, v22). Stage results are keyed on them: do not
edit them to reproduce the submission. `FINAL` names the three component files and their md5.
